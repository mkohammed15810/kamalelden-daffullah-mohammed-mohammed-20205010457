## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/mkohammed15810/kamalelden-daffullah-mohammed-mohammed-20205010457.git
```

### 2. Open the project

Open the downloaded folder using your preferred Java IDE.

### 3. Select a week

Navigate to the required weekly folder.

For example:

```text
week_10/
```

### 4. Compile and run

For a Java program with a `main` method:

```bash
javac Main.java
java Main
```

For the Quiz Battle application:

```bash
javac Questions.java QuizBattleGUI.java
java QuizBattleGUI
```

Depending on the IDE and Java version, you can also run the program directly using the IDE's **Run** button.
